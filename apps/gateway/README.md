# @plenum/gateway

The ready-to-run Plenum gateway.

- `pnpm gateway` from the repo root runs it with `examples/gateway.json`
- Or: `node apps/gateway/src/main.ts path/to/config.json`
- Currently runs simulator devices and prints to the console; Modbus, BACnet and MQTT plug in as they land

Part of [Plenum](../../README.md).
